# Improvement priorities

[← Project overview](../README.md)

These are proposed priorities, not features available in v0.1.0 or promised delivery dates.

| Priority | Area | A useful outcome |
| --- | --- | --- |
| 1 | General German dictionary coverage | Fewer missing everyday words and clearer distinctions between full definitions, terminology labels and reverse references |
| 2 | German word forms | More reliable lookup of inflected forms, with gender, plural and source information preserved |
| 3 | Installation and naming | Easier setup and consistent public branding in a future release |
| 4 | Customization | Useful display and export preferences that learners can change without editing source |
| 5 | Reading workflow | Improve lookup responsiveness and collection/review behavior using reproducible learner feedback |

Current documentation improvements include direct installation-package links, setup and backup instructions, screenshots and a source-code example.

For feedback, the most useful details are the queried word, the expected result with a source, the steps you took and your browser/OS version. [Open an issue](https://github.com/lizhegiballes-dot/german-learning-assistant/issues/new).
