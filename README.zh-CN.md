# German Learning Assistant（德语学习助手）

**在阅读的地方查词，把想学的词留下来。**

免费开源的 Chrome 扩展，支持划词查询、生词整理和 Anki 词单导出。

[**下载 Chrome 安装包 · v0.1.0**](https://github.com/lizhegiballes-dot/german-learning-assistant/releases/download/v0.1.0/wortglide-0.1.0.zip) · [English](README.md) · [安装与使用指南（英文）](docs/GETTING_STARTED.md)

</div>

我受够了在杜登查词时碰到的广告、缓慢加载和来回切换页面，于是做了 German Learning Assistant。查过的词可以按天查看，按书籍或课程整理，再拿去复习或导入 Anki。

## 从阅读到复习

| 你在做什么 | 扩展帮你保留什么 |
| --- | --- |
| 在支持的网页选词，或使用右键菜单 | 阅读位置旁的释义与来源 |
| 再次查询同一规范词头 | 同一条词记录和累计查询次数 |
| 阅读一本书、学习一门课 | 自己建立的分类，可指定新查词归入哪里 |
| 回看今天查过的词 | 按当天首次查询顺序排列的记录 |
| 收藏想学的词 | 个人笔记与可选的简单间隔复习 |
| 继续用 Anki 或其他工具学习 | Anki TSV、CSV 词单与 JSON 完整备份 |

界面语言和释义语言可以分别选择。命中本地词库后直接显示结果，省去打开词典整页的步骤；本地缺少英文释义时，可按需开启英文维基词典查询。

## 安装与首次使用

**需要 Chrome 116 或更新版本。目前通过 GitHub 手动安装，尚未上架 Chrome 扩展商店。**

1. [下载扩展安装包](https://github.com/lizhegiballes-dot/german-learning-assistant/releases/download/v0.1.0/wortglide-0.1.0.zip)，解压到长期保留的文件夹。
2. 打开 `chrome://extensions/`，开启「开发者模式」，点「加载已解压的扩展程序」。
3. 选择直接包含 **manifest.json** 的那一层。如果下载的是源码，选择 **extension** 文件夹。
4. 从工具栏打开扩展，选择界面与释义语言，再刷新正在阅读的网页。

如果需要补充英文释义，在「设置」开启「允许联网获取英文释义」。该选项默认关闭。德语发音使用已安装的本地系统声音，没有可用声音时会提示。

v0.1.0 的界面和压缩包文件名仍使用早期名称 **WortGlide**，它们就是本项目的当前发布版。不需要另外运行桌面后台。

## 先选分类，再开始阅读

先建立「这本书」「这门课程」等分类，再在设置中指定「新查词归入」。之后查到的词会自动加入该分类，也可以稍后批量整理。只想保留历史时，选择「只保留查询记录」。

在生词本按日期、分类或勾选词条筛选后，导出 **CSV 词单** 或 **Anki TSV**。TSV 可以在 Anki 导入时映射到对应的德语、英文或中文字段；它不是带图片、音频的 APKG 卡组包。

## 词库能查到哪些内容

| 来源 | 内容与范围 |
| --- | --- |
| **GEMET** | 5,352 个德语概念，含英文和／或中文术语标签，侧重环境及相关专业领域 |
| **HanDeDict** | 233,624 条德语到中文的反向精确匹配记录；这是匹配行数，不是不同德语词头数，结果会标为参考 |
| **英文维基词典** | 可选联网获取德语词条中的英文释义，默认关闭 |

当前词库仍有缺词、多义项和屈折变化识别不足的问题。中文未收录时会提示，并在已有英文释义时显示英文；不会自动编造中文词义。公开版不附带杜登或朗氏的词条、录音。

## 数据保存在哪里

学习记录保存在**当前 Chrome 用户资料中、这个扩展专属的浏览器数据库**里。它不会自动在桌面建立词单文件，也不会自动同步到其他设备。

设置页的「JSON 完整备份」会生成可以自行保管、或放进自己网盘的文件。卸载扩展、移动扩展文件夹或更换 Chrome 用户资料前，请先备份。**CSV／TSV 是词单，JSON 才用于恢复完整学习记录。**

查询事件在本机保留阅读页面的域名与路径，去除查询参数和片段；备份可能包含私人阅读信息，应自行妥善保存。可选联网查询仅发送查询词，不发送页面地址或生词本。项目没有自建云端、遥测或广告。[隐私说明](PRIVACY.md)。

## 常见问题

**选词后没有弹出？** 安装或更新后刷新网页，确认已开启「选词后自动弹出」。Chrome 内部页、扩展商店和部分特殊页面不支持；输入框与编辑区域也不会自动触发。

**有的词没有释义？** 尝试词典原形，并检查是否开启联网英文查询。当前版本的词库覆盖、中文释义和变形识别都有局限，联网也不保证每个词都能查到。

**没有发音？** 先安装本地德语系统声音。当前版本不使用远程语音。

**升级时怎么保留数据？** 先导出 JSON 备份，保留原扩展文件夹路径，在原目录更新文件后到扩展管理页点重新加载，再刷新阅读页面。不要先卸载旧扩展。
